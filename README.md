# Sawan Ade — Portfolio V2 (Bento Edition)

A minimalist, high-performance, single-sheet interactive bento portfolio inspired by modern Link3 profiles.

## Key Features
- **Single-Sheet Bento Layout:** All domains, projects, and research housed in a focused, mobile-first vertical card canvas.
- **Interactive Slide-Up Detail Sheets:** Tapping any project or inquiry smoothly slides up an in-depth modal sheet without page reloads or context loss.
- **Deep Linking Support:** Share direct links to specific projects using URL hash anchors (e.g. `#mirror`, `#ml4sci`, `#sir`).
- **Zero Runtime Dependencies:** Pure HTML5, CSS3, and modern vanilla JavaScript.
- **Deployable to GitHub Pages:** Includes `.nojekyll` for static hosting.
